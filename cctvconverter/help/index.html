Getting started

Install from the Microsoft Store and launch the app. Then:

  1. Open your footage — drag a recorder folder (or your DVR's SD card), or some video files, onto the window, or click Choose folder… or Choose files…. The app walks any date subfolders and lists every video file it finds. Once footage is open, the Source folder box at the top lets you switch to another folder.
  2. Pick an output folder — where converted MP4s are written. It must be a different folder from your recordings, so your originals are never overwritten. Your recent source and output folders are remembered for next time.
  3. Filter and tick — narrow the list with the search box and the duration, date and time filters, then click Tick matching (Reset clears the filters). Files that don't match are hidden and unticked, so only the files you can see get converted. The Tick: links above the list tick All or Unconverted files or Clear the ticks, and each day has its own tick box.

Everything runs on your own machine; nothing is uploaded.

Converting footage

Tick the files you want and click Convert ticked. Where the source stream is already MP4-compatible the app does a stream copy (no re-encoding, no quality loss, usually very quick); otherwise it re-encodes to clean H.264. Most of the settings below are in the Convert options menu next to the Output folder; the rest say where to find them.

  • Parallel conversion — convert several files at once (up to 16). A day of clips goes much faster on a multi-core PC.
  • Encoder — choose Auto, CPU, or a specific GPU (NVIDIA / Intel / AMD). Auto detects the best available and falls back to CPU if a GPU encode fails.
  • File names — keep the original name, add the date before or after it, or choose Custom… and build a name from {name}, {folder} and {date}.
  • Date/time burn-in — tick "Add timestamp overlay" to burn a per-frame clock into the bottom-left of the output, so the date and time are visible in the video itself.
  • Merge — from the Tools menu, combine any ticked clips into one continuous MP4 in time order, or right-click a day to merge the whole day.
  • CSV export — from the Tools menu, export the file list (name, size, duration, resolution, format, timestamps) for cataloguing.
  • Optional cleanup — "Delete source files after successful conversion" reclaims space as you go (with confirmation).
  • Unconverted tab — above the file list, switch from All to Unconverted to hide the files that are already converted, so you only see what is left to do.
  • Raw .264 / .265 files — these don't always store their playback speed. Where it can, the app works it out from the recording times in the file names; if a file still plays too fast or too slow, set the camera's frame rate under ⋯ › Recorded at.
  • Join and split — when recordings carry straight on from each other, a banner offers to join them into one video (the original files are unchanged). A file that holds several cameras shows a Split into … button on its row (also in its ⋯ menu) that makes one video per camera.
  • Settings and presets — the Settings button at the top holds the same conversion and watch-folder options, and lets you save them as a named preset to switch between in one click.

The built-in editor

Select a playable file (a converted MP4, or footage that already plays) and click Edit… under the preview to open the in-place editor. Its settings are arranged in five tabs — Clip, Privacy, Picture, Text & audio and Output — and a gold dot marks any tab you have changed. From there you can:

  • Trim — set the start and end points (down to a single frame) with the range slider or the I/O shortcuts, and mark multiple segments to export separately or merged.
  • Crop & rotate — crop to a region of interest or rotate footage that was recorded sideways.
  • Speed — make the exported copy play slower or faster (0.5× to 8×), for example to skim a long, quiet stretch.
  • Image adjustments — brightness, contrast, saturation, sharpness and gamma, with a live preview, plus one-tap look presets (Night, Bright, Clarify, Vivid, Black & White) shown as thumbnails.
  • Noise reduction — None / Light / Medium / Strong, to clean up grainy night footage.
  • Output size & quality — pick a resolution and quality level for the exported file. The Output tab shows an estimated file size before you save.
  • Text & audio — burn the date/time, a label or a watermark into the exported copy, or mute the audio.
  • Presets — save a combination of edit settings and reapply it in one click.

Click Save clip… to write a new MP4 (or use Export ▾ for the other formats below), then Done to go back to your files. Your original files are never modified. A progress bar (with cancel) shows the export as it runs.

Privacy — hide faces, plates & areas

On the editor's Privacy tab, click Detect faces to put a box on each face in the clip, then hide the ones you choose — or click Blur all faces to blur every face in one go, then review the boxes. Everything runs on your PC — nothing is uploaded. The tool only hides faces: it does not recognise or identify anyone.

  • Boxes that stay in place — each face gets a box that moves with it frame by frame, so it stays covered.
  • Choose which faces to hide — click a box to leave that face visible or to hide it; only the faces you pick are hidden.
  • Blackout, pixelate or blur — choose how hidden areas look, and use Box size to grow the face boxes so they cover the whole head.
  • Draw your own & keep it covered — turn on Hide areas manually, drag a box over anything — a number plate, a screen, a sign — and click Track this area to make the box follow that area automatically. Drag a box to move it, or its corner to resize it. If the same thing appears at other times too, draw another box there.

Automatic detection is a helpful first pass, not a guarantee — always play the clip back and cover anything left exposed before sharing.

More ways to export

The editor's Export ▾ menu offers more than a plain MP4:

  • For phone / WhatsApp — a small copy (16 MB or less) that plays on phones and can be sent in a chat.
    • Compress for email — re-encode to 25 MB or less for email or messaging.
    • Animated GIF — save a short moment as a looping GIF.
    • Evidence report — the source details and SHA-256 checksums, so a copy can be checked against the original, as a page that opens in any browser and can be printed to PDF.
    • Evidence package — a folder with a checked copy of the original recording, the MP4 as edited, a report listing what was changed, the checksums and a README.
    • Deinterlace & watermark — smooth combing on older analogue cameras, and burn a case number or watermark into the exported copy.

    Multi-camera view

    Tick two to six converted clips and choose Multi View from the Tools menu (or right-click a day) to watch the cameras side by side on a shared timeline. You can:

    • Nudge each camera's sync offset to line up clocks that have drifted apart.
    • Rename and rearrange cells, and solo a cell to hear its audio.
    • Pick a Layout (or leave it on Auto), swap two cameras round, and double-click a camera to see it full-window.
    • Snapshot all cameras at once, or build a combined contact sheet.
    • Export a synchronized composite video of the whole grid; click Stop to cancel an export that is running.

    Continuous timeline

    Right-click a day of recordings (or use its ⋯ menu or the Tools menu) and choose Play as timeline to watch the whole day's files as one continuous video — scrub across the joins, jump to the next motion once motion has been detected in those files, and export any span without opening each file separately.

    Motion highlights

    Tick footage and choose Extract motion highlights… from the Tools menu (or right-click a file or a day) to have the app scan for movement and keep only the clips where something happens.

    • Sensitivity — Low / Medium / High controls how much movement counts as an event.
    • Pre/post-roll — keep a few seconds before and after each event so nothing is clipped.
    • Output — save each event as its own file, or stitch them all into a single highlight reel.
    • Review — optionally review and deselect false positives before anything is written.

    Results are cached, so changing the pre/post-roll and re-exporting doesn't repeat the scan.

    You can also click Detect motion inside the editor to mark active stretches as segments and step between them with the prev/next-motion buttons.

    Filmstrip & motion heatmap

    In the preview, Show filmstrip adds a strip of thumbnails above the seek bar for fast scrubbing, and hovering the bar shows a preview pop-up. After a motion scan (Detect motion), a heatmap is painted along the seek bar so you can jump straight to the busy moments; use the prev/next-motion buttons to hop between events.

    Snapshot saves the current frame as a JPG (Ctrl+click copies it to the clipboard instead), and Fullscreen (or F) fills the screen.

    Watch-folder mode

    In the Convert options menu, turn on Watch source folder and the app rescans that folder whenever new recordings appear; turn on Auto-convert new files as well and it converts them too — a hands-off workflow for an always-on DVR. It waits until each file has finished being written before converting, and can pop a notification when a batch completes.

    Troubleshooting

    A file is flagged "can't convert"

    A few formats are genuinely undecodable by any third-party tool — most notably Hikvision encrypted backups (.crypt), which need Hikvision's own player. Standard Hikvision H.264 backups convert fine.

    A file won't convert because it's "in use"

    Another program (Windows' Films & TV, an Explorer preview, or antivirus) may be holding the file. Close any preview windows and try again; the app retries automatically for a few seconds.

    The preview won't play a source file

    Some raw CCTV formats can't be previewed until converted. Click Convert & view under the preview to convert the file and play it straight away.

    A raw file plays too fast or too slow

    Raw .264/.265 files don't always store their speed. Open the file's ⋯ menu, set the camera's frame rate under Recorded at, and the app offers to convert it again at the new speed.

    It says the output folder is the same as the source folder

    Converting into the folder that holds your recordings could overwrite them, so the app won't do it. Choose a different output folder — a new folder on the same drive is fine.

    Where are my settings and logs?

    Open About → Open log + cache folder. In the direct-download edition this is %LOCALAPPDATA%\CctvConverter\; the Microsoft Store edition keeps it inside its own app package folder, so the button is the easiest way there. It holds your config, the thumbnail cache and an error log — handy if you ever need to send a support report.

    Updates & support

    Each time it starts, the app checks whether a newer version is available. You can skip an optional update; a required update installs by itself, and the app closes and reopens when it is done. The Microsoft Store edition also updates through the Store. You can choose About → Check for updates at any time. The app makes no other network requests; see the Privacy Policy for details.
